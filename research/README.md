# Deep Research Reports — drop zone

Put the results of the deep-research queries (Section 5 of the plan) **here**, in this
`research/` folder, then commit & push. That's all I need — next session I read these files
and convert them into the app's study content (lessons, flashcards, quizzes, glossary,
interactive-tool data, Excel walkthroughs).

## How to upload

**Easiest (recommended):** save each report as a Markdown file in this folder using the names
below, then commit and push to the branch `claude/pe-internship-prep-program-DBiQz`.
On the Claude Code web/app you can also just **paste a report into the chat** and I'll save it
here for you.

## File naming convention

One file per query, Markdown preferred (`.md`). Keep the `Qxx-` prefix so order is preserved:

| `Q02-pe-fundamentals.md` | PE business model & fund lifecycle |
| `Q03-fund-economics-waterfalls.md` | Fees, carry, distribution waterfalls (worked math) |
| `Q04-performance-metrics-pme.md` | IRR / MOIC / TVPI / DPI / RVPI / PME & benchmarking |
